## Meqorist Review

The [Meqorist Review agent](.github/agents/meqorist.agent.md) is a general-purpose GitHub Copilot custom agent profile. Select it in a supported Copilot agent environment and ask it to review any halachic or religious claim. It examines how the Gemara defines the relevant rule and whether that definition applies to the case, flags gaps in the source chain, and does not treat later acceptance alone as proof of a connection to Chazal. Electricity on Shabbat is one possible subject, not a limit on the agent. It is invoked for a review; adding the profile does not automatically run reviews. Available search and web tools depend on the Copilot environment.
