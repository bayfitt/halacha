## Meqorist Review

The [Meqorist Review agent](.github/agents/meqorist.agent.md) is a GitHub Copilot custom agent profile. Select it in a supported Copilot agent environment and ask it to review a document or claim. For electricity on Shabbat, it examines each proposed melachah or other prohibition, how the Gemara defines it, and how that definition is argued to apply to the particular electrical action. It flags gaps in the source chain and does not treat later acceptance alone as proof of a connection to Chazal. It is invoked for a review; adding the profile does not automatically run reviews. Available search and web tools depend on the Copilot environment.
